The Studio

Small team. Short catalogue. Long support.

We release fewer games than most studios our size, and we keep working on them for years. A title that ships in March should still be getting fixes the following winter — that is the standard we set for ourselves.

01 / Interface

Nothing on screen that is not needed

If an element does not help you play, it does not belong in the layout. We remove furniture rather than add it.

02 / Progression

Earned, never purchased

Every level in every game is reachable without spending. Store items are cosmetic or convenience, never a key.

03 / Reliability

Tested where it hurts

Low-end Android hardware, weak networks, interrupted sessions. If it breaks there, it does not ship.

Flagship

Rommel — a puzzle built to be finished.

Our flagship title is a hand-authored logic puzzle with no clock and no penalty for thinking. Each board introduces one idea, then asks you to combine it with everything the game has taught you so far.

Hints are free and unlimited. Progress saves on every move, and the whole game runs offline — on a plane, in a lift, or on a train that has given up on signal entirely.

Standards

Four rules we will not trade away.

Rule 01

No manufactured waiting

We never bolt energy bars or cooldowns onto a game that does not need them. Difficulty belongs in the puzzle, not in the shop.

Rule 02

Prices before the press

Anything purchasable is priced and described before you commit. No invented countdowns, no recurring "limited" offers.

Rule 03

Minimal collection

We gather only what is needed to run and improve the game, set out plainly in our Privacy Policy.

Rule 04

Fix before feature

A known crash is repaired before new content begins. A broken build is not a roadmap item — it is a broken product.
